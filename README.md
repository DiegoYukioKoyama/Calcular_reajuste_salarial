# 📈 Exercício de Recálculo de Salários

Este é um projeto simples em Python desenvolvido para resolver um exercício de manipulação de listas, tuplas e estruturas condicionais.

## 📋 Descrição do Exercício
O objetivo é desenvolver um algoritmo que construa uma lista de tuplas contendo o **nome** e o **salário** de funcionários. Em seguida, o código deve recalcular os salários considerando as seguintes regras de aumento:
*   **20%** para salários de até R$ 2.000,00;
*   **15%** para salários entre R$ 2.000,00 e R$ 5.000,00;
*   **5%** para salários maiores que R$ 5.000,00.

Ao final, o programa exibe:
1. O total gasto com o aumento (Soma dos novos salários - Soma dos antigos).
2. Os nomes dos funcionários que tinham salários menores que R$ 2.000,00.

## 🛠️ Tecnologias Utilizadas
*   **Python 3** (Nenhuma biblioteca externa é necessária).

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:
   ```bash
   python main.py
   ```
